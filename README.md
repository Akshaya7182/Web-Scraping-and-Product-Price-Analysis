# Air Conditioners Data Analysis – Final Stage-Wise Project

## Dataset
**Air_Conditioners_Cleaned.csv** — 720 rows × 14 columns.

## Stage-wise workflow
1. Data Loading and Reading
2. Data Acquisition & Filtering
3. Data Extraction
4. Data Validation & Cleaning
5. Data Aggregation & Representation
6. Data Analysis
7. Data Visualization
8. Results & Interpretation

Every stage is an independent Google Colab-ready `.ipynb` with detailed explanation and code containers. Every notebook reads the CSV directly using `pandas.read_csv()` and includes a stage README.

## Execution
Open any stage notebook in Google Colab and run from top to bottom. The stages are designed to be understandable individually while preserving the full project pipeline.
