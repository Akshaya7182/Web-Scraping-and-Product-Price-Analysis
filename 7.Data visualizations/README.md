# Stage 7 – Data Visualization

**Presented by:** K. Sai Krishna (Sai)

**Files:** `07_Data_Visualization.ipynb`

## What this stage does
Nine Matplotlib charts: price histogram, average price by brand, listings by brand, energy-star pie, price by tonnage, price-vs-rating scatter, discount histogram, price-by-star box plot, correlation heatmap.

## Output
PNG files in `charts/`.

## Key techniques
`plt.hist`, `barh`, `pie`, `scatter`, `boxplot`, `imshow`

## How to run
Open the notebook in Google Colab or Jupyter and run the cells top to bottom. The notebook finds its input in `../0. DataSet/`
(or in `/content` / the current folder; in Colab it will ask you to upload the file if it is missing).
Run the stages in order 1 → 8 because each stage uses the output of the previous one.
