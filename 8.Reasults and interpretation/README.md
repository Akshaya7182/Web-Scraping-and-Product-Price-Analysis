# Stage 8 – Results & Interpretation

**Presented by:** T. Yeghna Surya Teja (Yeghu)

**Files:** `08_Results_and_Interpretation.ipynb`

## What this stage does
Recaps the data funnel, generates key findings in plain language directly from the data, lists best-value products, and gives buyer / seller interpretation, limitations, conclusion and future scope.

## Output
`Results_Key_Findings.csv`.

## Key techniques
f-string generated findings, conditional interpretation, weighted rating

## How to run
Open the notebook in Google Colab or Jupyter and run the cells top to bottom. The notebook finds its input in `../0. DataSet/`
(or in `/content` / the current folder; in Colab it will ask you to upload the file if it is missing).
Run the stages in order 1 → 8 because each stage uses the output of the previous one.
